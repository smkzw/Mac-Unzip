# MacUnzip

Application native pour parcourir, prévisualiser, extraire et créer des archives sur Mac. Elle nécessite macOS 26 ou une version ultérieure et une puce Apple (arm64).

La version de distribution v1.3.0 inclut `7zz` 26.03 (arm64) pour le format 7z, sans installation via Homebrew. Une compilation Debug peut utiliser un exécutable `7zz` externe détecté.

Les images DMG et ISO sont ouvertes en lecture seule. La création d’archives RAR nécessite l’outil officiel de RARLAB.
