- 清理工程遗留命名，修正 CI 构建链，移除废弃的旧项目文件

## 首次打开提示
本版本为 ad-hoc 签名、未经 Apple 公证。若系统提示无法打开，请在 Finder 中右键该应用 → 打开；或在终端执行：

```
xattr -dr com.apple.quarantine /Applications/Mac解霸.app
```
