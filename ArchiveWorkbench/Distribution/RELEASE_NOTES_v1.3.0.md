# Mac 解霸 v1.3.0

- **加密 ZIP 与 7z**：修复密码会话在预览、解压和拖出文件时的衔接，并改进拖到 Finder 的文件交付。应用通过私有标准输入将密码传给 7z 引擎。
- **TAR 与 TGZ**：修复 TAR、TAR.GZ（含 `.tgz`）的打开流程。解压时检查路径，拒绝 TAR 中的符号链接和硬链接。
- **新建压缩包**：创建面板可混合拖入文件、文件夹和已有压缩包。重复输入会跳过，归档内顶层名称冲突可重命名、替换或取消。
- **原生界面**：更新应用图标、欢迎页、创建面板和压缩包浏览界面。
- **内置 7z 引擎**：Release 构建内置经过哈希校验的 7-Zip `7zz` 26.03（arm64），使用 7z 无需 Homebrew。创建 RAR 仍需 RARLAB 官方 `rar`。
- **开源许可**：应用采用 MIT 许可证，第三方组件保留各自许可。同步清理了仓库的退役素材和内部过程资料。

## 系统要求与首次打开

需要搭载 **Apple 芯片（arm64）**、运行 **macOS 26 或以上版本**的 Mac。

此版本采用 **ad-hoc 签名，未经过 Apple 公证**。校验 DMG 后，将应用拖入「应用程序」并尝试打开。如果 macOS 拦截，且已确认下载来源可信，可前往「系统设置 → 隐私与安全性」，选择「仍要打开」并确认。 [Apple 官方说明](https://support.apple.com/zh-cn/102445)

## 文件与校验

将 `MacUnzip-1.3.0.dmg` 和 `MacUnzip-1.3.0.dmg.sha256` 放在同一目录。校验文件使用相对文件名 `MacUnzip-1.3.0.dmg`，可在该目录运行：

```sh
shasum -a 256 -c MacUnzip-1.3.0.dmg.sha256
```
