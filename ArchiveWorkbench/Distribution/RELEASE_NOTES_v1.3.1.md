# Mac 解霸 v1.3.1

这是 **v1.3.0 的修正版**：补上密码确认后的自动续接。v1.3.0 已支持加密 ZIP/7z 的列出与密码横幅，但输入正确密码后只重新打开归档，不会继续原先的解压或拖出，目标目录可能仍为空。

## 本版修正

- **ZipCrypto 兼容**：修复 vendored minizip `mz_strm_pkcrypt` 对 Info-ZIP/`zip -P` 传统加密的错误实现（CRC32 补码与校验字节），使系统加密 ZIP 在正确密码下可解密并续接解压/拖出。
- **解压续接**：全部解压或选中解压因密码中断时，记住目标目录与选中项；密码正确后无需再次点击即可继续输出文件。
- **拖出续接**：文件/文件夹拖到 Finder 时若需密码，保留接收方目标与 completion；解锁后自动物化并安全发布，completion 只完成一次。等待密码有超时上限（约 90 秒）；超时、取消或切换压缩包会清理 staging 并给出应用内错误，避免静默无结果。
- **预览续接**：预览因密码中断时，解锁后重试原条目；若用户在确认前已改选其他条目，则不覆盖。
- **错误密码**：错误密码不会触发续接；切换/关闭文档或取消横幅会清除 pending，不会在新归档上执行旧操作。
- 仍保留最多 3 次密码尝试、`SecurePassword` 生命周期，以及既有的原子发布与冲突处理。

## 继承自 v1.3.0

v1.3.0 的能力仍然有效，包括：加密 ZIP/7z 密码会话与私有标准输入传密、TAR/TGZ 打开与链接拒绝、新建压缩包混合拖入与顶层冲突处理、原生界面更新、Release 内置经哈希校验的 7-Zip `7zz` 26.03（arm64）、MIT 许可与第三方声明。创建 RAR 仍需另行安装 RARLAB 官方 `rar`。

## 系统要求与首次打开

需要搭载 **Apple 芯片（arm64）**、运行 **macOS 26 或以上版本**的 Mac。

此版本采用 **ad-hoc 签名，未经过 Apple 公证**。校验 DMG 后，将应用拖入「应用程序」并尝试打开。如果 macOS 拦截，且已确认下载来源可信，可前往「系统设置 → 隐私与安全性」，选择「仍要打开」并确认。

## 文件与校验

将 `MacUnzip-1.3.1.dmg` 和 `MacUnzip-1.3.1.dmg.sha256` 放在同一目录。校验文件使用相对文件名 `MacUnzip-1.3.1.dmg`，可在该目录运行：

```sh
shasum -a 256 -c MacUnzip-1.3.1.dmg.sha256
```
