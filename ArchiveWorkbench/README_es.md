# MacUnzip

Aplicación nativa para explorar, previsualizar, extraer y crear archivos comprimidos en Mac. Requiere macOS 26 o posterior y un chip de Apple (arm64).

La compilación de distribución v1.3.0 incorpora `7zz` 26.03 (arm64) para el formato 7z, sin necesidad de Homebrew. Una compilación Debug puede usar un ejecutable externo `7zz` si lo detecta.

Las imágenes DMG e ISO se abren en modo de solo lectura. Para crear archivos RAR se necesita la herramienta oficial de RARLAB.
