# MacUnzip

App nativa per sfogliare, visualizzare in anteprima, estrarre e creare archivi su Mac. Richiede macOS 26 o successivo e un chip Apple (arm64).

La build di distribuzione v1.3.0 include `7zz` 26.03 (arm64) per il formato 7z, senza richiedere Homebrew. Una build Debug può usare un eseguibile `7zz` esterno se viene rilevato.

Le immagini DMG e ISO si aprono in sola lettura. La creazione di archivi RAR richiede lo strumento ufficiale di RARLAB.
