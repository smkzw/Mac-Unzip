# MacUnzip

압축 파일을 탐색하고 미리 보고 풀거나 만들 수 있는 macOS용 네이티브 앱입니다. Apple Silicon(arm64) 및 macOS 26 이상이 필요합니다.

배포용 v1.3.0에는 7z용 `7zz` 26.03(arm64)이 포함되어 있어 Homebrew가 필요 없습니다. 소스에서 빌드한 Debug 버전은 감지된 외부 `7zz`를 사용할 수 있습니다.

DMG와 ISO 이미지는 읽기 전용으로 열립니다. RAR 파일을 만들려면 RARLAB의 공식 도구가 필요합니다.
