# MacUnzip

アーカイブの閲覧、プレビュー、展開、作成ができる macOS ネイティブアプリです。Apple シリコン（arm64）と macOS 26 以降が必要です。

配布用の v1.3.0 には 7z 用の `7zz` 26.03（arm64）が同梱されており、Homebrew は不要です。ソースからの Debug ビルドでは、検出された外部の `7zz` を使用できます。

DMG と ISO は読み取り専用で開きます。RAR の作成には RARLAB 公式のツールが必要です。
