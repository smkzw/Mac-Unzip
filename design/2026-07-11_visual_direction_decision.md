# Archive browser visual direction

The July 2026 design established one archive window with two views. The [approved visual target](assets/adaptive-finder-media-visual-target-v3.png) records the intended layout. See the [current project screenshots](../README.md) for examples of the current interface.

- Standard view uses a Finder-style archive tree and table, with a collapsible inspector.
- Media view keeps the archive tree visible alongside a large preview and a keyboard-navigable filmstrip.
- Both views share the toolbar, selection, navigation, and archive state.
- Use the system material for window controls. Keep list and preview content legible with Reduce Transparency and Increase Contrast enabled.
