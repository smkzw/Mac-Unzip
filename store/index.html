MacUnzip

Browse, preview, extract, and create archives on your Mac.

Download on GitHub View source

macOS 26+ · Apple silicon (arm64) · MIT License

Preview files

Browse and search archives, preview supported images, videos, PDFs, and documents, and extract selected files.

Work with common formats

Browse and create ZIP, 7z, and compressed TAR archives. The v1.3.0 Release build includes 7zz 26.03 for 7z, RAR reading, and read-only DMG and ISO access. No Homebrew setup is needed. RAR creation needs the external RARLAB rar tool.

Process archives locally

Extraction applies path and resource checks. The optional online engine-version check retrieves version metadata.
