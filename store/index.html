Frequently Asked Questions

Mac解霸要求 macOS 14.0 (Sonoma) 或更高版本。完全支持 Apple Silicon (M1/M2/M3/M4) 和 Intel Mac。应用使用原生 SwiftUI 构建，在 Apple Silicon 上性能表现尤为出色。
免费版支持解压所有格式和基础预览。Pro 版额外提供：全格式应用内预览（图片/视频/PDF/代码高亮）、创建 6 种格式压缩包、AES-256 加密、安全防护三件套（path traversal + symlink + quarantine）、崩溃恢复原子日志、CJK 编码自动检测。这些高级功能在同类免费工具中完全不存在。
我们对比了 The Unarchiver、Keka、BetterZip、WinZip 等所有主流 macOS 解压工具，没有任何一款同时提供 Path Traversal 防护、Symlink 攻击拦截和 Quarantine 隔离标记这三重安全机制。恶意压缩包可以通过路径穿越将文件写入系统任意位置，或通过符号链接攻击绕过沙盒。Mac解霸是唯一认真对待这些威胁的解压工具。
完全不需要联网。Mac解霸使用 Ed25519 椭圆曲线数字签名算法进行离线验证。激活码本身包含加密签名，应用在本地验证签名有效性即可激活。整个过程零网络请求、零数据收集、零隐私泄露。你的信息永远不会离开你的 Mac。
我们相信好工具不应该有高价门槛。Mac解霸由独立开发者打造，没有庞大的营销团队和企业开销。$9.99 (¥49) 一次买断，终身使用，包含所有未来更新。相比 BetterZip 的 $35、WinZip 的 $29.99、Bandizip 的 ¥148，我们提供更强的功能（安全防护、崩溃恢复、全格式预览），价格却只有它们的三分之一。
很多早期在 Windows 下创建的 ZIP 压缩包使用 GBK/GB2312 编码存储中文文件名，而 macOS 默认使用 UTF-8，导致解压后文件名显示为乱码。Mac解霸内置 CJK 编码自动检测引擎，能智能识别 GBK、GB2312、Big5、Shift_JIS、EUC-KR 等东亚编码，自动转换为正确的 Unicode 文件名。The Unarchiver 仅有有限支持，Keka、BetterZip、WinZip 均不支持此功能。
