Why MacUnzip?

Built from scratch in Swift for Apple Silicon. Not an Electron wrapper. Not a Python script. A real Mac app.

🔒

Military-Grade Security

8-layer defense: path traversal blocking, symlink scanning, FD-relative operations, resource bomb detection, atomic writes, process isolation, sandboxed preview, and quarantine tagging. Every archive is treated as potentially hostile.

⚡

Native Performance

Pure Swift 6 with async/await concurrency. Zero Electron overhead. Extraction runs at full Apple Silicon speed with memory-mapped I/O and parallel decompression.

👁️

Built-in Preview

View images, videos, PDFs, and markdown files inside archives without extracting. QuickLook integration lets you preview any file with a single spacebar press.

📦

40+ Formats

ZIP, RAR, 7z, TAR, GZ, BZ2, XZ, DMG, ISO, and more. Create archives in 6 formats with optional AES-256 encryption. Nested archive browsing included.
