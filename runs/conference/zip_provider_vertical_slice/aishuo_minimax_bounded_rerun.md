# MiniMax-M3 中文体验复核

## 边界
仅基于 Codex 提供的七项固定证据包做中文术语、用户工作流、命令层级与能力表达复核。
不读源码、不跑命令、不验收视觉。本轮结论不依赖任何缺失的渲染截图或 UI fixture 实测。

## 已通过
1. 标题层级真实：左侧标题为实际 ZIP 文件名、第二行为路径+搜索条件下的 `visibleEntries.count`，单行中间截断、无圆角背景——不假装“项目名/项目描述”，符合诚实原则（事实：证据 1）。
2. 主工具栏未混入“检测完整性”，一致把它当作二级动作处理（事实：证据 1、2）。
3. `操作` 菜单顺序为 共享 / 标签 / 检测完整性 / 分隔线 / 当前操作，符合 macOS 二级菜单习惯，分隔线区分一次性动作与常驻动作（事实：证据 2）。
4. 真实 provider 与 UI fixture 都设 `canTestIntegrity = false`，且没有“已排队”假状态——不会对用户撒谎“测试中”（事实：证据 2）。
5. 侧边栏从 ZIP 条目生成顶层文件夹并附实际文件数，根目录归入“压缩包根目录”，替换旧静态假文件夹——Finder 化、不再造假数据（事实：证据 3）。
6. 列表四列 名称 / 类型 / 大小 / 修改日期，名称列仅显末级名、完整路径保留在元数据与搜索，符合 Finder 行为（事实：证据 4）。
7. 错误文案按 11 类明确区分（密码、加密、压缩、分卷、路径、限额、源变更、读取失败、格式、损坏等），不会因“未知错误”掩盖原因（事实：证据 5）。
8. 搜索为原生 NSSearchField，宽/窄屏占位分别为“搜索压缩包内容”“搜索”，搜索结果与侧边栏共同决定 `visibleEntries`，标题计数随之更新——可达、不假装（事实：证据 6）。
9. 添加 / 解压缩 / 完整性检测等未接入能力全部禁用并显式提示接入条件，不画大饼（事实：证据 7）。

## 仍需修改
当前证据包内无中文体验阻断项。

唯一轻微观察（建议级，非阻断）：根分类名“压缩包根目录”略显生硬，与 Finder 习惯的“无本文件夹”或“根”表述不完全一致；如下一轮允许文案微调，建议考察是否对齐 macOS 习惯或保留以避免歧义为“另一文件夹”。
